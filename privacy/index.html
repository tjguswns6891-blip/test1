개인정보처리방침

마르코프 (@markovspace) · 시행일 2026년 10월 10일

마르코프(이하 "운영자")는 인스타그램 계정 @markovspace의 게시물에 남겨진 댓글에 자동으로 안내 메시지(DM)를 보내는 서비스(이하 "서비스")를 운영합니다. 이 방침은 서비스가 어떤 정보를 어떻게 처리하는지 설명합니다.

1. 처리하는 정보

누군가 @markovspace 게시물에 댓글을 남기면, Instagram(Meta)이 서비스에 다음 정보를 전달합니다.

  • 댓글 ID, 댓글 내용
  • 댓글 작성자의 Instagram 사용자 ID와 사용자 이름
  • 댓글이 달린 게시물 ID

서비스는 이 밖의 정보(이름, 연락처, 위치, 결제 정보 등)를 수집하지 않습니다.

2. 이용 목적

  • 댓글에 특정 키워드(예: "링크")가 있는지 확인
  • 키워드가 있으면 작성자에게 요청한 웹사이트 링크를 DM으로 1회 보내고, 댓글에 확인 답글을 남김
  • 같은 댓글에 DM이 중복으로 가지 않도록 방지

광고, 마케팅 목록 작성, 프로필 분석, 제3자 판매에는 사용하지 않습니다.

3. 보관 기간

  • 댓글 내용과 사용자 이름은 저장하지 않으며, 처리 즉시 폐기합니다.
  • 중복 발송 방지를 위해 댓글 ID만 최대 8일간 보관하고, 기간이 지나면 자동 삭제됩니다.
  • 오류 확인용 서버 로그는 호스팅 업체 정책에 따라 짧은 기간 후 자동 삭제됩니다.

4. 제3자 제공 및 처리 위탁

운영자는 정보를 제3자에게 판매하거나 제공하지 않습니다. 서비스 운영을 위해 다음 업체의 인프라를 이용합니다.

  • Meta Platforms (Instagram API): 댓글 수신과 DM 발송
  • Cloudflare (Workers): 서비스가 실행되는 서버와 댓글 ID 임시 보관

5. 이용자의 권리

이용자는 언제든 자신의 정보 열람과 삭제를 요청할 수 있습니다. 방법은 데이터 삭제 안내를 확인하세요. 자동 DM을 받고 싶지 않다면 키워드가 들어간 댓글을 남기지 않거나, 받은 DM 대화에서 계정을 차단하면 됩니다.

6. 아동

서비스는 Instagram 이용 약관에 따라 Instagram을 이용할 수 있는 사람을 대상으로 하며, 만 14세 미만 아동의 정보를 의도적으로 수집하지 않습니다.

7. 문의

개인정보 관련 문의는 Instagram @markovspace DM으로 보내주세요.

8. 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.

Privacy Policy (English summary)

Markov (@markovspace) runs an automation that replies by Instagram Direct Message when someone comments a keyword on @markovspace posts. Through Instagram webhooks we receive the comment ID, comment text, the commenter's Instagram user ID and username, and the media ID. We use them only to send one private reply containing the requested website link and to post a short public reply. Comment text and usernames are not stored; only the comment ID is kept for up to 8 days to prevent duplicate messages, then deleted automatically. We do not sell or share data. Processors: Meta Platforms (Instagram API) and Cloudflare (Workers hosting). To request deletion, see the data deletion instructions. Contact: Instagram DM to @markovspace. Effective October 10, 2026.
