캡션은 길게 풀어 쓰고 "댓글에 🔥노하우텔링🔥 남겨주세요 → 자료 보내드림"으로 댓글 유도 (댓글이 좋아요의 2배).

**핵심 = 노하우텔링**: 정보만(AI로 대체됨) ✕, 스토리텔링만(한 번 보고 끝) ✕
→ **내 경험이 정보가 되고, 내 관점이 전문성이 된다.**

## 우리 대본에 적용할 규칙
1. **첫 문장은 '나' + 구체 숫자 + 기간.** "~하는 방법 알려드릴게요" 대신 "제가 ~해 봤더니 ~됐어요".
   - 선형대수: "행렬식 쉽게 이해하는 법" → "제가 선대 기호 때문에 막혀서, 아예 사이트를 만들었어요"
   - 증시: "이번 주 증시 정리" → "제가 이번 주 고용보고서 보고 제일 놀란 숫자는 2만 9천이에요"
2. **정보 문장마다 내 경험·판단 한 줄**을 붙인다 (내가 해 봤다 / 내가 헷갈렸다 / 나는 이렇게 본다).
3. 숫자는 비교로: "5억→3억", "10분 만에", "50% 저렴" 처럼 전후·기간·비율.
4. 쇼츠는 한 문장 2~3초, 주제 하나에 두 문장(일반론 → 내 버전). 대비 포맷(OLD vs NEW, 교과서 vs 내 사이트)도 쓸 만함.
5. 끝은 **댓글 키워드 유도** + 받을 것 약속: "댓글에 '행렬' 남기면 연습 문제 링크 보내 드릴게요".
6. 캡션은 영상보다 길게: 문제 → 왜 → 내가 한 것 → 댓글 키워드.

## 릴스 캡션 규칙
- 해시태그는 **가장 효과 좋은 5개만** (주제 핵심 2~3개 + 넓은 카테고리 1~2개). 10개씩 나열하지 않는다.

## 쇼츠 화면 배치 (기본값, shorts.py)
- 카드·화면 칸을 가로 꽉 차게 크게(0,390~1080,1000), **얼굴은 아래로 떨어뜨려 작게**(crop-w 1000, person-y 950), 자막은 카드와 얼굴 사이(y 1015) 한 자리 고정.

## 참고 릴스 ② 치상(ourproject_chisang) "편집 초보가 제일 많이 하는 실수" (댓글 1,124)
https://www.instagram.com/reel/Dd5DVuaTGMe/ · 44초 · 9:16, 앉아서 카메라 보고 말하기

**대본 구조**
1. 0~8초 O/X 훅: "이렇게 하지 말고 이렇게 하세요" × 4번 (2초씩). 화면에 나쁜 예/좋은 예 두 장을 나란히, 빨간 "X"·초록 "O" 라벨.
2. "핵심은 이겁니다" → 편집 전에 정할 것 (시청자가 먼저 볼 게 텍스트냐, 영상·소리냐).
3. "제일 많이 하는 실수": 자막 위치가 위아래로 왔다 갔다 → 눈이 자막 찾느라 내용을 놓친다 → **처음 그 자리에 고정**.
4. 카메라 보고 말하는 영상은 자막 필수 (릴스는 대부분 소리 끄고 봄).
5. CTA: "친구한테 보내 주세요" + "팔로우하고 댓글에 '콘텐츠' 남기면 효과음·편집틀·폰트 보내 드림".

**편집 스타일**
- 자막: **한 줄, 8~14자 짧은 덩어리**, 상자 없이 흰 글씨 + 부드러운 검은 그림자, 가슴 높이 한 자리 고정. 강조 문장만 노란색.
- 그래픽은 얼굴 옆·위 빈 벽에 작게 (예시 화면, 폰트 목록). 얼굴은 가리지 않음.
- 말에 맞춰 아이콘 팝: ❌(하지 마세요), 🔇(소리 없이), 강조 문장 밑줄 두 줄.

**우리 영상에 적용**
- 쇼츠 자막을 두 줄 → 한 줄 짧게 끊기 (한 줄 12자 안팎), 위치는 지금처럼 고정.
- 쇼츠 첫 3초를 O/X 대비 훅으로: "107조 벌었다 ⭕ → 주가는 올랐다 ❌".
- 말에 맞춰 ❌/⭕/↓ 아이콘 팝 넣기.
- CTA에 댓글 키워드 + 받을 것 약속 (예: 댓글에 "사이트" → 테마 순위 사이트 링크).
