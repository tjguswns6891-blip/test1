# ★ 쇼츠·릴스 표준 제작 순서 (2026-10-14 확정 — 앞으로 이대로)
AI 음성(얼굴 없는) 쇼츠·릴스는 아래 순서를 기본으로 한다. 선대 4편 v2(reels4)가 기준 예시.
1. **대본** (reels4/script.json 형식): 첫 대사는 3초 안 · 주제어 포함 · "OO 주목 + 주제어 + 반전/질문", tts 는 `!`/`?` 로 끝.
   `*단어*` 로 강조 표시: 첫 대사 주제어 1 + 본문 2~4 (핵심 숫자·대비어·정답 단어). 숫자는 받아쓰기 표기대로(`*5개*`, `*59049*`).
   음성 모델이 자주 틀리는 말은 미리 바꾼다 (예: "소거하면" → "행 소거를 하면").
2. **음성**: `tools/tts_voxcpm_para.py script.json raw/voice/prompt_hook.wav "$(cat raw/voice/prompt_hook.txt)" 출력폴더`
   → 첫 대사 5번 중 최고 선택(릴스·쇼츠 공용) + 본문 + 강조(크기·앞 쉼) + ×1.12 빠르기 자동.
3. **발음 검수**: 완성 음성을 받아쓰기(faster-whisper medium)로 대본과 대조. 핵심 단어가 틀리면 그 음성만 `--seed` 바꿔 다시 만든다 (첫 대사는 재사용).
4. **합성**: `tools/faceless.py` — 자막은 한두 문장씩 통째로, 받아쓰기 단어 시각에 맞춰 시작(대본↔받아쓰기 글자 정렬), 강조 단어는 노란색.
   싱크 검사: 자막마다 시작 시각의 들리는 단어가 자막 첫 단어와 같은지 확인 (어긋남 0 이어야 함). 그래픽 칸이 말과 맞는지 프레임으로 확인.
5. **효과음**: sfx.py, 반 볼륨, 30초 기준 4~8개 (영상이 짧으면 개수 줄이기) — intro · visual · emph · trans · cta.
6. **업로드**: video-files 브랜치에 올린 뒤 커밋 고정 주소로 Metricool 예약. 플랫폼은 사용자가 말한 곳만.
   유튜브 쇼츠 제목 끝에 해시태그 3개 (`#shorts #선형대수 #공대생` 식), 설명란에 사이트 링크, 카테고리 교육, 아동용 아님.
   AI 표시는 사용자 요청으로 끔. 고정 댓글은 사용자가 직접(Metricool 불가). 게시 10분 뒤 게시 여부·링크 확인해서 알려 주기.

## 우리 대본에 적용할 규칙
1. **첫 문장은 '나' + 구체 숫자 + 기간.** "~하는 방법 알려드릴게요" 대신 "제가 ~해 봤더니 ~됐어요".
   - 선형대수: "행렬식 쉽게 이해하는 법" → "제가 선대 기호 때문에 막혀서, 아예 사이트를 만들었어요"
   - 증시: "이번 주 증시 정리" → "제가 이번 주 고용보고서 보고 제일 놀란 숫자는 2만 9천이에요"
2. **정보 문장마다 내 경험·판단 한 줄**을 붙인다 (내가 해 봤다 / 내가 헷갈렸다 / 나는 이렇게 본다).
3. 숫자는 비교로: "5억→3억", "10분 만에", "50% 저렴" 처럼 전후·기간·비율.
4. 쇼츠는 한 문장 2~3초, 주제 하나에 두 문장(일반론 → 내 버전). 대비 포맷(OLD vs NEW, 교과서 vs 내 사이트)도 쓸 만함.
5. 끝은 **댓글 키워드 유도** + 받을 것 약속: "댓글에 '행렬' 남기면 연습 문제 링크 보내 드릴게요".
6. 캡션은 영상보다 길게: 문제 → 왜 → 내가 한 것 → 댓글 키워드.

- **참고 음성은 raw/voice/prompt_hook.wav** (페이저 릴스 앞 8초, 가장 힘 있는 말투) + prompt_hook.txt 대본.
- **대본 sub 에 `*단어*` 로 강조 2~4곳 + 후킹 주제어 1곳**: 주제어(후킹 첫 문장 안), 핵심 숫자, 대비어(최대·0·딱 하나·한 상만), 정답 단어.
  숫자는 받아쓰기 표기대로 숫자로 쓴다 (`*5개*`, `*59049*`). 자막에서도 그 단어가 노란색으로 나온다.
- **tts 첫 문장은 느낌표**로 (`공대생 주목!`), 질문형 후킹은 물음표.
- tts_voxcpm_para.py 가 생성 뒤 emphasize.py 로 자동 처리: 표시 단어 +2반음·+3.5dB, 첫 3초 +2dB, 전체 ×1.12 빠르게.

### 첫 대사(후킹)는 따로 공들인다 — 가장 중요 (사용자 요청)
- 첫 대사는 **3초 안**, 12~18음절. 주제어를 첫 대사 안에 반드시 넣고 `*주제어*` 표시 (예: `공대생 주목. *엑셀 추세선*, 사실 선형대수예요.`).
- tts 는 느낌표·물음표로 끝낸다. 상위 릴스 패턴: "OO 주목. + 주제어 + 반전/질문" (페이저, 아직도 외우세요? / 초보가 99% 헷갈리는 KVL, KCL).
- 음성 생성 때 첫 대사만 **5번 따로 만들어 가장 힘 있는 것**을 고른다 (tts_voxcpm_para.py --hook-takes 5):
  받아쓰기 일치도 0.85 미만 탈락 → 음높이 폭 + 0.5×최고 음 튐 − 2×|말 빠르기−6.5음절/초| 점수 최고. 후보·점수는 `<키>_<판>.hook/scores.json`.
- 첫 대사 안의 표시 단어는 본문보다 세게: **+3.5반음 · +5dB** (본문 표시 단어는 +2반음 · +3.5dB), 첫 대사 전체 +2dB.
- 첫 대사 뒤 0.3초 쉼 → 본문. 자막·커버·제목 첫 줄을 첫 대사와 같은 말로 맞춘다.

## 영상 제작 도구 (2026-10-12 설치, 스킬: .claude/skills · 새 세션: `bash youtube/tools/setup_video_tools.sh`)
기존 파이프라인(autocut → compose → sfx → shorts)은 그대로 메인. 아래 도구는 **모션 카드·설명 애니메이션·배경**을 만드는 데 쓴다.
- **HyperFrames** (`hyperframes init/render`, 스킬 /hyperframes · motion-graphics · talking-head-recut): HTML+GSAP 장면 → MP4. 기존 motion.html 카드를 대체/강화 — 숫자 카운트업, 차트, 로고 스팅, 하단 자막바. 10초 렌더 ≈ 12초. 세로(1080x1920) 쇼츠용 카드도 바로.
- **Remotion** (스킬 /remotion-*): React로 자막·차트·전환. 데이터 기반 반복 영상(매일 증시 지표 카드 템플릿)에 적합. `npx remotion render src/index.ts <id> out.mp4`.
- **Manim** (`~/.venvs/manim/bin/manim`, 스킬 manim-composer · manimce-best-practices, LaTeX 있음): 3Blue1Brown식 설명 애니메이션. 선형대수(행렬 변환·고유벡터), 회로이론(KVL/KCL 식, 전류 흐름) 사이트 소개·개념 쇼츠에 사용.
- **algorithmic-art** (p5.js): 썸네일·인트로·배경용 움직이는 제너러티브 아트(회로 기판 흐름, 벡터장, 주가 파티클).
- **Blender** (4.0, 헤드리스 EEVEE): `blender -b --factory-startup --python 장면.py -- 출력폴더` (예: youtube/reels2/blender). 1280x720 · 샘플 8 → 프레임당 약 3초. PNG 연속 프레임 → ffmpeg. 다크 배경 + 사이트 색. MCP for Blender(앱 연동)는 화면이 없어 안 씀.
