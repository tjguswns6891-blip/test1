## 남은 것
1. 받기: `git fetch origin video-files && git archive origin/video-files 라플라스_작업중 | tar -x` 후 `raw/laplace/` 로 옮김
2. 음성: `sh raw/laplace/tts_rest.sh` (롱폼 나머지 21조각 → 쇼츠/릴스 A·B·C, 이미 있는 건 건너뜀)
3. 발음 검사(받아쓰기) → 틀린 조각만 --seed 바꿔 다시
4. 합성: `python3 tools/longform.py laplace/long.json -o raw/laplace/long --name long`
   쇼츠/릴스: `cd laplace && python3 ../tools/faceless.py reels.json -o ../raw/laplace/reels --only A --avatar ../profile/profile_real_B.png` (B, C, shorts.json 도)
5. 싱크 검사 → 효과음(sfx.py) → video-files 업로드 → 전달
