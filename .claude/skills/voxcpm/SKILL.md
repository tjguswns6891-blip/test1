# VoxCPM2 — 한국어 안내

이 안내 스킬은 **리본랩스가 쓴 것**이다. 본체는 제작자의 것이다 — `OpenBMB/VoxCPM`(Apache-2.0)이고, 리본랩스는 제작자와 제휴 관계가 없다. 우리는 쓰는 법만 한국어로 옮겼다. 아래 내용은 저장소 README 에 있는 것만 적었다.

## 무엇인가

README 소개: VoxCPM2 는 **2B 파라미터** 음성 합성 모델이고, **30개 언어**(한국어 포함)를 지원하며, **보이스디자인**(목소리를 말로 설명해 만들기)과 **제어 가능한 음성복제**를 하고, **48kHz** 음질로 출력한다. 가중치와 코드는 **Apache-2.0** 이라 상업 이용이 가능하다고 README 가 밝힌다.

## 먼저 알아 둘 것

- **요구 사양** (README): Python 3.10 이상 3.13 미만 · PyTorch 2.5.0 이상 · CUDA 12.0 이상. 즉 엔비디아 GPU 환경을 전제로 한 안내다. 이 설치기는 모델을 받거나 돌리지 않는다.
- **오용 금지** (README): 사칭·사기·허위정보 목적으로 쓰는 것은 엄격히 금지돼 있다. AI 로 만든 소리는 AI 가 만들었다고 표시하라고 권한다. 남의 목소리는 그 사람의 동의가 있을 때만 복제한다.
- **결과가 매번 다르다** (README): 보이스디자인과 제어 복제는 실행마다 달라서, 원하는 목소리가 나올 때까지 1~3번 다시 뽑아 보라고 한다.
- 결과를 보증하지 않는다. 클로드 코드 구독은 따로다.

## 설치

```
pip install voxcpm
```

## 보이스디자인 — 참고 음성 없이 목소리를 설명으로 만든다

`text` 맨 앞에 **괄호로 목소리 설명**을 붙인다. 형식은 `"(목소리 설명)읽을 문장"` 이다.

```python
wav = model.generate(
    text="(A young woman, gentle and sweet voice)Hello, welcome to VoxCPM2!",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("voice_design.wav", wav, model.tts_model.sample_rate)
```

(`model` 을 불러오는 앞부분은 README 의 Python API 절을 그대로 따른다.)

## 음성복제 — 참고 음성 한 개로 음색을 따라 한다

```python
wav = model.generate(
    text="This is a cloned voice generated by VoxCPM2.",
    reference_wav_path="path/to/voice.wav",
)
```

괄호 설명을 같이 주면 속도·감정 같은 스타일도 조절한다(README 의 제어 가능한 음성복제).

```python
wav = model.generate(
    text="(slightly faster, cheerful tone)This is a cloned voice with style control.",
    reference_wav_path="path/to/voice.wav",
)
```

README 의 「궁극 복제」는 참고 음성과 **그 음성의 정확한 대본**을 함께 주는 방식이다(`prompt_wav_path` · `prompt_text`).

## 명령줄 (CLI)

```
voxcpm design --text "읽을 문장" --output out.wav

voxcpm design --text "읽을 문장" --control "Young female voice, warm and gentle" --seed 42 --output out.wav

voxcpm clone --text "읽을 문장" --reference-audio path/to/voice.wav --output out.wav

voxcpm clone --text "읽을 문장" --prompt-audio voice.wav --prompt-text "참고 음성의 대본" --output out.wav

voxcpm batch --input 입력.txt --output-dir outs
voxcpm --help
```

- `design` 은 참고 음성이 필요 없고, `clone` 은 `--reference-audio` 가 필요하다.
