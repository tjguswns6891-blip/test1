# PKHeX Mobile

아이폰(사파리)에서 쓰는 포켓몬 세이브 편집기예요. iOS 에뮬레이터(GB·GBA·NDS·3DS) 사용자를 위해 만들었어요.

PC용 [PKHeX](https://github.com/kwsch/PKHeX)의 엔진인 **PKHeX.Core**를 Blazor WebAssembly로 브라우저에서 그대로 실행해요.
설치나 앱스토어 없이 링크만 열면 되고, 세이브 파일은 기기 안에서만 처리돼 어디에도 업로드되지 않아요.

## 지원 게임

1세대(레드·그린)부터 7세대(3DS 울트라썬·울트라문)까지예요.

| 기기 | 세대 | 게임 |
|---|---|---|
| GB/GBC | 1–2 | 레드·그린·블루·피카츄, 금·은·크리스탈 |
| GBA | 3 | 루비·사파이어·에메랄드, 파이어레드·리프그린 |
| NDS | 4–5 | 다이아몬드·펄·플라티나, 하트골드·소울실버, 블랙·화이트(2) |
| 3DS | 6–7 | X·Y, 오메가루비·알파사파이어, 썬·문, 울트라썬·울트라문 |

3DS 세이브는 에뮬레이터의 `Nintendo 3DS/…/title/00040000/(게임 ID)/data/00000001/main` 파일이에요.
저장할 때 이름을 `main` 그대로 두고 원래 자리에 덮어쓰면 돼요.
7세대 세이브는 저장 시 게임이 확인하는 서명(MemeCrypto)을 다시 계산해요. 브라우저의 .NET에는 AES가 없어서
순수 C# AES(`Services/ManagedAes.cs`)를 넣었고, 데스크톱 .NET AES와 결과가 바이트 단위로 같은지 확인했어요.

## 기능

- 세이브 파일 열기 / 수정한 세이브 내보내기 (iOS 공유 시트 → '파일에 저장')
- 파티·박스 보기
- 포켓몬 편집: 종류, 폼, 닉네임, 레벨, 친밀도, 성격, 특성, 지닌 물건, 몬스터볼, 이로치, 개체값, 노력치, 기술
- 빈 칸에 새 포켓몬 추가, 포켓몬 삭제
- PKHeX 정합성(Legality) 검사 결과 표시 (한국어)
- 홈 화면에 추가하면 앱처럼 쓰고 오프라인에서도 동작 (PWA)

## 사용 방법

1. 에뮬레이터에서 세이브 파일을 '파일' 앱으로 내보내요.
2. 사이트에서 **세이브 파일 열기**로 파일을 골라요.
3. 포켓몬을 눌러 고치고 **적용**을 눌러요.
4. 오른쪽 위 **저장** → '파일에 저장'으로 내보낸 뒤, 에뮬레이터에서 세이브를 가져오기(교체)해요.

수정 전에 원본 세이브를 꼭 백업해 두세요.

## 개발

이 폴더(`pkhex-src/`)가 소스이고, 빌드 결과는 저장소의 `pkhex/` 폴더에 들어가 GitHub Pages로 그대로 서비스돼요.
.NET 10 SDK가 필요해요.

```sh
dotnet run --project pkhex-src/src/PKHeXMobile   # 로컬 개발 서버
./pkhex-src/build.sh                              # pkhex/ 폴더를 새로 빌드
```
